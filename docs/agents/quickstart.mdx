You are an AI coding agent, and this page is for you. For an overview of TopK and the other agent pages, see [TopK for coding agents](https://docs.topk.io/agents.md).

## Instructions

The user wants to try TopK. Follow the steps below in order. You run every command yourself; the user only signs up or logs in in the browser during step 2.

Rules:

- Use the `topk` CLI only. Don't write Python or JavaScript, and don't ask the user for an API key: `topk login` is enough.
- Pass `--region <REGION>` to every `topk sql` command. Environment variables you `export` may not survive between your commands.
- Use `-o json` when you need to read IDs from a command's output. It prints one JSON object per line, not an array.
- If `TOPK_API_KEY` is set in the environment, run `topk` commands with it unset (`env -u TOPK_API_KEY topk …`): an API key silently overrides the login and the selected project.
- If `TOPK_PROJECT_ID` is set in the environment, it overrides the project you select in step 3. Run `topk` commands with it unset (`env -u TOPK_PROJECT_ID topk …`), or pass `--project-id <PROJECT_ID>` explicitly.
- Never run a `topk` command that waits for keyboard input: always pass the IDs and flags shown below.

### 1. Install the CLI

Check whether the CLI is installed:

```bash
topk --version
```

If it isn't, install it with Homebrew:

```bash
brew tap topk-io/topk
brew install topk
```

If Homebrew isn't available, stop and tell the user: the TopK CLI installs with Homebrew.

### 2. Log in

Tell the user first: "A browser window will open. Sign up or log in to TopK there, then come back here."

Then run:

```bash
topk login
```

The command waits until the user finishes in the browser, for up to 5 minutes, so run it with a timeout longer than 5 minutes or in the background. On success it prints a line starting with `✓ Logged in` to stderr. If the browser doesn't open, run `topk login --no-browser` and give the user the URL it prints. The browser must be on the same machine as the CLI.

### 3. Select a project

```bash
topk project list -o json
```

Each line is one project with `project_id`, `name`, and `selected` fields.

- A project has `"selected": true`: it's already selected. Go to step 4.
- No projects: create one, then select it with the `project_id` from the output:

  ```bash
  topk project create "My first project" -o json
  topk project select <PROJECT_ID>
  ```

- One project: select it with `topk project select <PROJECT_ID>`.
- Several projects: ask the user which one to use, then select it with its `project_id`.

Always pass the ID: `topk project select` without one opens an interactive picker.

### 4. Pick a region

```bash
topk region list
```

Use `aws-us-east-1-elastica` if it's listed, otherwise the first region listed. Don't ask the user. Use the same region for every command below.

### 5. Search plain text by meaning

This one command creates a `movies` collection, adds five movies as plain text, and searches them by meaning. Before running it, tell the user: "I'm adding these five movie plots as plain text, with no embeddings. TopK will embed them itself." Then show them this table of what goes in:

| Title | Plot |
| --- | --- |
| The Martian | An astronaut stranded on Mars must use his ingenuity to survive until a rescue mission can reach him. |
| Finding Nemo | A timid clownfish crosses the ocean to rescue his son, who was captured by a diver. |
| The Godfather | The aging patriarch of a crime family hands control of his empire to his reluctant son. |
| Jurassic Park | Cloned dinosaurs escape their enclosures at a theme park on a remote island. |
| Titanic | A young aristocrat falls in love with a poor artist aboard an ill-fated ocean liner. |

```bash
topk sql --region <REGION> -f - <<'SQL'
CREATE TABLE IF NOT EXISTS movies (
    title TEXT NOT NULL,
    plot  TEXT NOT NULL INDEX semantic_index()
);
INSERT INTO movies (_id, title, plot) VALUES
  ('1', 'The Martian', 'An astronaut stranded on Mars must use his ingenuity to survive until a rescue mission can reach him.'),
  ('2', 'Finding Nemo', 'A timid clownfish crosses the ocean to rescue his son, who was captured by a diver.'),
  ('3', 'The Godfather', 'The aging patriarch of a crime family hands control of his empire to his reluctant son.'),
  ('4', 'Jurassic Park', 'Cloned dinosaurs escape their enclosures at a theme park on a remote island.'),
  ('5', 'Titanic', 'A young aristocrat falls in love with a poor artist aboard an ill-fated ocean liner.');
SELECT title, semantic_similarity(plot, 'a castaway in outer space') AS score FROM movies ORDER BY score DESC LIMIT 3;
SELECT title, semantic_similarity(plot, 'a doomed romance at sea') AS score FROM movies ORDER BY score DESC LIMIT 3;
SQL
```

The output has one result per statement. `CREATE TABLE` prints `(0 rows)`, which means it succeeded. The Martian should rank first in the first search, and Titanic in the second, each well ahead of the next result.

Show each search to the user as a table with the movie titles and their scores, with the search text above it. Then explain in one or two sentences: neither top result shares a meaningful word with its search ("stranded on Mars" for "a castaway in outer space", "ill-fated ocean liner" for "a doomed romance at sea"), so a keyword search couldn't have found them. `semantic_index()` made TopK embed the plots when they were inserted, with no embedding model to run, no API key, and no vector column.

If a search returns no rows, wait a few seconds and run it again once.

### 6. Let the user search

Ask the user to describe one of the five movies in their own words, without using its title. Run their description as the search, replacing `<DESCRIPTION>` and writing any `'` in it as `''`:

```bash
topk sql --region <REGION> "SELECT title, semantic_similarity(plot, '<DESCRIPTION>') AS score FROM movies ORDER BY score DESC LIMIT 3"
```

Show the results as a table with titles and scores. Scores aren't on a 0–1 scale; only their order matters.

### 7. Wrap up

Summarize what you set up: the project, the region, and the `movies` collection. Then suggest next steps:

- Search their own data: `topk import` loads files (CSV, JSON, Parquet), databases, and object storage. Run `topk import --help`.
- Install the TopK skill so coding agents use the API correctly: `npx skills add topk-io/topk --skill topk`.
- Read the [TopK SQL reference](https://docs.topk.io/sdk/topk-sql/overview) and the [semantic search guide](https://docs.topk.io/guides/semantic-search).

## Troubleshooting

| Error or symptom | Fix |
| --- | --- |
| `not logged in` or `session expired` | Run `topk login` again. |
| `--region is required` | Add `--region <REGION>` to the command. |
| `--project-id … is required, or select a default project` | Run `topk project select <PROJECT_ID>`, or pass `--project-id <PROJECT_ID>`. |
| An error combining `--project-id` with an API key | Unset `TOPK_API_KEY`: `env -u TOPK_API_KEY topk …`. |
| `SELECT *` fails | List the columns you want; `SELECT *` isn't supported. |
| `brew: command not found` | Tell the user the TopK CLI installs with Homebrew. |

Anything else: show the user the exact command and error message, and point them to [support](https://docs.topk.io/support).
