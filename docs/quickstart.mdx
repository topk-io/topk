Paste this into Claude Code, Cursor, Codex, or any coding agent with terminal access:

```text
Set up TopK: docs.topk.io/start
```

The agent sets everything up from the CLI. You only sign up or log in in the browser window it opens.

## What the agent does

1. Installs the [TopK CLI](/cli) with Homebrew.
2. Opens a browser so you can sign up or log in.
3. Selects a project and the region closest to you.
4. Creates a `movies` collection with a semantic index, so it can be searched by meaning.
5. Adds a dozen documents and runs a semantic search and a keyword search.

When it's done, it can load 50,000 Wikipedia articles from Hugging Face and run a true hybrid search over them.

## Prefer to do it yourself?

Follow the [hybrid search example](/introduction#hybrid-search) with the Python or JavaScript SDK, or use the [CLI](/cli) directly.
