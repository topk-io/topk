## Get started

<div className="get-started">
<CardGroup cols={2}>
  <Card title="Python SDK" icon="/icons/python.svg" href="/sdk/topk-py/overview">
    Search from Python. TopK embeds your text for you.

    ```python
    # pip install topk-sdk
    client.collection("books").query(
      select(
        score=fn.semantic_similarity(
          "content", "meaning of life"
        ),
      )
      .sort(field("score"), asc=False)
      .limit(10)
    )
    ```
  </Card>

  <Card title="JavaScript SDK" icon="/icons/js.svg" href="/sdk/topk-js/overview">
    Search from TypeScript or JavaScript. Same API.

    ```typescript
    // npm install topk-js
    await client.collection("books").query(
      select({
        score: fn.semanticSimilarity(
          "content", "meaning of life"
        ),
      })
      .sort(field("score"), false)
      .limit(10)
    );
    ```
  </Card>

  <Card title="CLI" icon="terminal" href="/cli">
    Import data and run SQL from your terminal.

    ```bash
    brew tap topk-io/topk
    brew install topk
    topk login
    topk import ./books.parquet \
      --region aws-us-east-1-elastica
    ```

    <Tip>
      `topk login` doesn't select a project. Run `topk project list`, then `topk project select <PROJECT_ID>`, or pass `--project-id <PROJECT_ID>` to each command. `TOPK_PROJECT_ID` overrides the selected project when set.
    </Tip>
  </Card>

  <Card title="SQL" icon="database" href="/sdk/topk-sql/overview">
    Search with any PostgreSQL client.

    ```sql
    SELECT title,
      semantic_similarity(content,
        'meaning of life') AS score
    FROM books
    ORDER BY score DESC LIMIT 10;
    ```
  </Card>
</CardGroup>
</div>
